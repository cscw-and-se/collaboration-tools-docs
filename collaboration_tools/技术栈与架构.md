# 技术栈速览

## 技术选型一览

| 技术 | 用在哪 | 为什么选它 |
| --- | --- | --- |
| TypeScript | 全部包 | 类型安全，协议消息结构靠类型约束，编译期发现错误 |
| Yjs | `open-collaboration-yjs` | CRDT 算法，无需服务器仲裁冲突，客户端自动合并 |
| Socket.IO | server + protocol | 自动降级，内置重连，比裸 WebSocket 更稳定 |
| Express | server | 轻量，处理 HTTP 认证端点（`/api/login/*`） |
| InversifyJS | server + vscode | DI 容器，解耦服务生命周期，`autoBindInjectable` 减少样板代码 |
| msgpackr + fflate | protocol | 二进制编码 + 可选压缩，减少高频编辑时的带宽消耗 |
| npm workspaces | 根目录 | monorepo，包间引用不需要发布到 npm |

## Monorepo 构建

根目录 `package.json` 定义了 workspaces：

```json
"workspaces": [
  "packages/*"
]
```

所有子包共享依赖，`npm install` 在根目录执行一次即可。构建用 esbuild（`scripts/esbuild.ts`），TypeScript 编译用 `tsc -b tsconfig.build.json`。

## Docker 部署

```bash
docker compose build
docker compose up -d
```

服务端镜像基于 Node.js 22，通过环境变量配置认证方式和端口（详见 [项目是怎么运行的](how_it_works.md)）。
