## 1. Vim 的编辑方式

Vim 用“操作符 + 对象”的方式编辑文本，而不是逐字输入。比如 `dw` 删除一个单词，`d$` 删除到行尾。熟练之后，很多编辑动作靠键盘就能完成，不必在鼠标和键盘之间来回切换。

## 2. 模式

- **Normal（默认）**：用于移动和命令。
- **Insert**：按 `i` 进入，像普通编辑器一样打字；按 `Esc` 返回 Normal。
- **Command-line**：按 `:` 进入，如 `:w` 保存、`:q` 退出、`:wq` 保存并退出。
- **Visual**：按 `v` 进入，选中文本后再操作。

一个基本习惯：敲完字就按 `Esc` 回到 Normal。

## 3. 导航

```text
:42         跳到第 42 行
0 / $       行首 / 行尾
w / b       下 / 上一个单词
/<keyword>  搜索，按 n 跳下一个
gg / G      文件开头 / 结尾
```

## 4. 编辑

```text
dd      删除整行
u       撤销
Ctrl-r  重做
yy      复制当前行
p       粘贴
d / y   配合 v 选中后删除 / 复制
```

## 5. 分屏与宏

```text
:split / :vsplit   水平 / 垂直分屏
Ctrl-w w           在分屏之间切换
q<register>        把操作录制到某个寄存器
@<register>        回放录制的操作
```

宏适合处理重复的结构化改动，例如把一个很大的表格整理成 CSV。

## 6. 配置与取舍

`.vimrc` 可以配置语法高亮、自动缩进和快捷键。常见的其他编辑器：

- **Emacs**：扩展性强，有自己的生态；也有人用 Evil Mode 在 Emacs 里套用 Vim 的按键。
- **Nano**：上手简单，适合快速的单文件修改。

通过 SSH 登录远程服务器时通常没有图形界面，Vim 基本是必备工具。

## 小结

Vim 的价值不在于快捷键多，而在于把编辑文本变成一套可组合的操作，减少手在鼠标和键盘之间反复移动。
